# 토픽 허브: 텍스트 분석 (text-analysis)

> [!info] 토픽 노트는 그래프에 노드로 export되지 않습니다 — build 스크립트는 `vault/papers/` 만 스캔합니다.
> 이 노트는 사람(그리고 정독 세션)이 문헌 지형을 조망하기 위한 MOC(Map of Content)입니다.

뉴스·공시·텍스트 데이터를 경제 상태변수로 변환하는 축입니다. 현재 vault에서는 단일
노드만 있는 **의도적 공백 영역**으로, 그래프의 공백 모드에서 고립 노드로 표시됩니다 —
축적이 진행되면 내러티브 경제학, 공시 텍스트, LLM 기반 측정 연구로 확장할 후보 축입니다.
